======================================================================
  GUÍA DE DESPLIEGUE: CÓMO HACER FUNCIONAR EL JUEGO DE MEMORIA (XAMPP)
======================================================================

Sigue estos pasos detallados para configurar el entorno, crear las
carpetas e importar la base de datos para que el juego ande al 100%.

----------------------------------------------------------------------
PASO 1: UBICACIÓN Y ESTRUCTURA DE CARPETAS
----------------------------------------------------------------------
1. Abre tu explorador de archivos e ingresa a la ruta raíz de XAMPP:
   C:\xampp\htdocs\

2. Dentro de 'htdocs', crea una nueva carpeta llamada 'memory'. La ruta
   exacta debe quedar así:
   C:\xampp\htdocs\memory\

3. Abre Visual Studio Code, ve a File > Open Folder... (Archivo > Abrir 
   carpeta) y selecciona la carpeta 'memory' que acabas de crear.

4. Crea los siguientes 3 archivos dentro de esa carpeta en VS Code:
   ├── index.html          (Contiene la interfaz y lógica en JavaScript)
   ├── guardar.php         (Controla el envío de récords a MySQL)
   └── obtener_ranking.php (Consulta el Top 5 de mejores puntajes)

   *Pega los códigos de corrido correspondientes en cada archivo.*

----------------------------------------------------------------------
PASO 2: ENCENDER LOS SERVICIOS EN XAMPP
----------------------------------------------------------------------
1. Abre el panel de control de XAMPP (XAMPP Control Panel).
2. Haz clic en el botón "Start" de los siguientes dos módulos:
   - Apache  (Servidor web para procesar los archivos PHP)
   - MySQL   (Servidor de base de datos)
3. Ambos módulos deben ponerse en color VERDE.

----------------------------------------------------------------------
PASO 3: CONFIGURAR LA BASE DE DATOS EN PHPMYADMIN
----------------------------------------------------------------------
1. Abre tu navegador web favorito (Chrome, Edge, Firefox, etc.).
2. Ingresa a la siguiente dirección: http://localhost/phpmyadmin/
3. En la barra lateral izquierda, haz clic en "Nueva" para crear una BD.
4. En el campo 'Nombre de la base de datos', escribe exactamente:
   juegomemory
5. Deja el cotejamiento por defecto y haz clic en el botón "Crear".
6. Una vez creada, haz clic sobre 'juegomemory' en la barra lateral, ve 
   a la pestaña "SQL" en el menú superior, pega el siguiente código y 
   presiona "Continuar":

   CREATE TABLE IF NOT EXISTS ranking (
       id INT AUTO_INCREMENT PRIMARY KEY,
       jugador VARCHAR(50) NOT NULL,
       intentos INT NOT NULL,
       tiempo_segundos INT NOT NULL DEFAULT 0,
       fecha TIMESTAMP DEFAULT CURRENT_TIMESTAMP
   );

----------------------------------------------------------------------
PASO 4: EJECUTAR Y PROBAR EL JUEGO
----------------------------------------------------------------------
1. En tu navegador, abre una nueva pestaña e ingresa a la URL:
   http://localhost/memory/index.html

2. ¡Listo! El juego cargará mezclando las cartas de forma aleatoria.
3. Si fallas tus intentos, puedes presionar "Reiniciar partida".
4. Al ganar, introduce tu nombre en el recuadro flotante. El ranking
   inferior se actualizará automáticamente con tu nueva puntuación.
======================================================================
